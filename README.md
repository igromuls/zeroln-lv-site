# zeroln.lv

The Latvian website of SIA "ZeroLN". The English site is zeroln.com (repository igromuls/zeroln-site).

The files are generated. Do not edit them here. The source is `tools/site_build.py` in the private manager folder.
Run the tool, then copy `store/site-lv/` into this repository.

Hosting: GitHub Pages, branch `main`, folder `/ (root)`, custom domain `zeroln.lv` (see `CNAME`).
